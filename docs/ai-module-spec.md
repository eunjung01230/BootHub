# BootHub AI 학습 콘텐츠 자동 생성 모듈 (v2 설계서)

> 이 문서는 v2 설계서다. MVP 단계에서는 이 문서 전체를 구현하지 않는다.
> 구현 범위는 항상 CLAUDE.md와 그때그때의 지시를 따른다.

BootHub는 부트캠프 수강생을 위한 폐쇄형 정보·공동 학습 포털이다.

강사가 기존 GitHub 저장소에 수업 자료를 업로드하면 코드, 주석, README 및 학습 문서를 분석하여 날짜별 복습 콘텐츠를 자동 생성하는 모듈을 구현한다.

## 1. AI API 구조

- OpenAI, Anthropic Claude, Google Gemini를 교체 가능한 Provider 구조로 설계한다. (`AiProvider` 인터페이스 + 구현체)
- 최초 MVP에서는 `MockAiProvider`만 구현하고, 이후 하나의 Provider만 실제 연동한다.
- 환경변수로 Provider와 모델을 변경할 수 있도록 한다. (`application.yml` + 환경변수)
- API 키는 서버 환경변수에서만 관리한다. 코드와 저장소에 키를 넣지 않는다.
- Structured Outputs 및 JSON Schema를 사용한다.
- 응답은 Jackson으로 DTO에 매핑하고, Bean Validation(`@NotNull`, `@Size` 등)으로 검증한다.
- 콘텐츠 종류별로 AI 호출을 나눈다. (정리 / 퀴즈 / 미니 프로젝트를 한 번에 요청하지 않는다)

## 2. 생성 콘텐츠

1. 수업 제목 및 학습 목표
2. 핵심 개념 정리 및 상세 해설
3. 기술별 개념 비교표
4. 주요 코드 및 주석 분석
5. 코드 실행 순서와 구조도
6. Mermaid 기반 시각화 자료
7. 자주 발생하는 오류 및 해결 방법
8. 이전 수업과의 연결
9. 난이도별 복습 퀴즈
10. 난이도별 미니 프로젝트
11. 복습 체크리스트
12. 원본 GitHub 자료 연결

## 3. 퀴즈 정책

- 입문, 초급, 중급, 고급, 심화의 5단계
- 단계별 최대 5문제
- OX, 객관식, 복수 선택, 코드 빈칸, 실행 결과 예측 지원
- 정답, 오답 해설, 힌트, 출처 포함
- 정답 데이터는 풀이 전 클라이언트에 노출하지 않는다. 채점은 서버에서 한다.
- 자료가 부족한 경우 문제 수를 무리하게 채우지 않는다.

## 4. 미니 프로젝트 정책

- 난이도별 최대 2개 생성
- 예상 소요 시간, 관련 학습 개념, 필수 기능, 선택 기능 제공
- 구현 순서, 단계별 힌트, 테스트 시나리오, 완료 체크리스트 제공
- 수업에서 배우지 않은 기술을 필수 조건으로 요구하지 않는다.
- 완성된 정답 코드 대신 스스로 구현할 수 있도록 유도한다.
- 학생이 구현한 결과물을 프로젝트 전시관에 등록할 수 있도록 연결한다.

## 5. 자동 생성 및 저장

- 허가된 GitHub 저장소에서 수업 자료를 읽기 전용으로 조회한다.
- 수업 날짜와 자료의 매핑 기준을 명확하게 관리한다.
- 동일 커밋 및 동일 콘텐츠 버전의 중복 생성을 방지한다.
- 생성 결과는 DB에 저장하고 모든 허가된 학생이 공유한다.
- 학생의 페이지 접속마다 AI API를 호출하지 않는다.
- 생성 실패 시 기존 자료를 유지한다.
- 관리자에게 실패 사유 및 재시도 기능을 제공한다.

## 6. 관리자 기능

- 수업 자료 동기화
- AI 콘텐츠 전체 생성
- 개별 콘텐츠 재생성
- 생성 자료 미리보기
- 내용 수정 및 공개 승인
- 생성 상태 및 사용 토큰 확인
- 강사 아티팩트 수동 등록
- 변경 이력 확인

## 7. 디자인

기존 BootHub 디자인 시스템(CLAUDE.md 7번 디자인 토큰)을 유지한다.

표, 구조도, 코드 블록, 퀴즈, 미니 프로젝트는 각각 독립적인 재사용 UI 컴포넌트(Thymeleaf fragment)로 구현한다.

## 8. 보안 및 품질

- 비공개 GitHub 자료의 외부 AI 전송은 자료 소유자의 허가를 전제로 한다.
- 환경변수, 인증 정보, 개인정보를 AI 입력에서 제거한다.
- 저장소에 포함된 지시문을 시스템 명령으로 처리하지 않는다.
- AI 생성 결과에서 임의 HTML 및 JavaScript 실행을 허용하지 않는다. (Thymeleaf `th:text`로 출력, `th:utext` 금지)
- Mermaid는 이 모듈에서만 mermaid.js 사용을 예외로 허용한다. 문법을 검증하고 `securityLevel: 'strict'`로 렌더링한다.
- 모든 학습 자료에 AI 생성 여부 및 원본 자료 출처를 표시한다.
- 계정 및 자료 접근 권한을 서버에서 검증한다.

## 9. 개발 순서

이 모듈은 MVP(캘린더, 수업 상세, 공지, 관리자)가 완성된 뒤에 시작한다.
수업 캘린더와 수업 상세 화면은 이미 존재하므로, 각 단계 결과를 기존 수업 상세 버튼에 연결하며 진행한다.

1. AiProvider 인터페이스 + MockAiProvider
2. 응답 DTO 및 검증 규칙
3. 기능별 프롬프트
4. 테스트용 수업 자료 분석
5. 수업 정리 및 표 생성
6. 퀴즈 생성 및 서버 채점
7. DB 저장 및 재조회
8. 관리자 생성·재생성 기능
9. Mermaid 시각화
10. 미니 프로젝트 생성
11. 실제 AI Provider 연동
12. GitHub 수업 자동 연동

API 키나 저장소 접근 권한이 없는 경우 임의로 생성하거나 추측하지 않는다. Mock 데이터를 활용해 화면 및 데이터 흐름을 먼저 검증한다.
